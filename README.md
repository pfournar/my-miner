# My Miner

Πρόγραμμα mining για κάρτες γραφικών **NVIDIA και AMD**. Δείχνει ποιο κρυπτονόμισμα αφήνει κέρδος με **το δικό σου ρεύμα**, διαλέγει τον miner και το pool με τα μικρότερα fees και τρέχει το mining. Η σελίδα «Αγορά κάρτας» δείχνει ποια κάρτα συμφέρει να αγοράσεις, με τιμές από το BestPrice.

Δημιουργός: **pfournar**, Ηλεκτρολόγος Μηχανικός & Μηχανικός Υπολογιστών ΕΜΠ (NTUA) · Άδεια: **MIT**, ελεύθερο λογισμικό, δωρεάν.

## Κατέβασμα

👉 **[Τελευταία έκδοση](https://github.com/pfournar/my-miner/releases/latest)**: κάτω στα «Assets», κατέβασε το **`MyMiner-x.y.z.zip`** (όχι τα «Source code»).

1. Δεξί κλικ στο zip → **«Εξαγωγή όλων»**, όπου θέλεις (π.χ. Έγγραφα ή D:\\).
2. Άνοιξε το **`MyMiner.exe`** μέσα στον φάκελο «My Miner».
3. Την πρώτη φορά τα Windows μπορεί να δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας». Πάτα **«Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε»**. Αυτό εμφανίζεται σε κάθε νέο πρόγραμμα χωρίς πληρωμένο πιστοποιητικό και **δεν** σημαίνει ότι βρέθηκε ιός.

Είναι **portable**: δεν θέλει εγκατάσταση και κρατάει ρυθμίσεις, wallets, logs και miners δίπλα στο `MyMiner.exe`. Για άλλον υπολογιστή αντιγράφεις όλο τον φάκελο. Νέες εκδόσεις έρχονται από μέσα από το πρόγραμμα («⬆ Νέα έκδοση» / «⟳ Έλεγχος ενημέρωσης»).

## Έλεγχος γνησιότητας

Το `MyMiner.exe` είναι **ψηφιακά υπογεγραμμένο από τον pfournar**. Το αποτύπωμα (thumbprint) του πιστοποιητικού είναι:

```
F02CB4693F3DE90BD74F70635BD5D6058F016C26
```

**Ο εύκολος τρόπος:** κατέβασε το **[`Έλεγχος γνησιότητας.cmd`](Έλεγχος%20γνησιότητας.cmd)**, βάλ' το στον φάκελο «My Miner» δίπλα στο `MyMiner.exe` και άνοιξέ το. Πρέπει να γράψει **✓ ΓΝΗΣΙΟ**. Μπορείς και να σύρεις μέσα στο παράθυρό του το zip, για να το ελέγξεις πριν το αποσυμπιέσεις.
- Είναι λίγες γραμμές κειμένου που ρωτάνε τα **ίδια τα Windows** για την υπογραφή. Ανοίγει και στο Notepad, για να δεις τι κάνει.
- Ισχύει για **όλες τις εκδόσεις**. Κράτα το στον φάκελο και ξανατρέξ' το όποτε θέλεις.
- Για απόλυτη σιγουριά, σύγκρινε το αποτύπωμα που γράφει μέσα του (και που φαίνεται παραπάνω) με αυτό που σου έχει πει ο δημιουργός **από άλλο κανάλι** (π.χ. Viber).

**Χωρίς τον ελεγκτή:** δεξί κλικ στο `MyMiner.exe` → Ιδιότητες → **Ψηφιακές υπογραφές** → pfournar → Λεπτομέρειες → Προβολή πιστοποιητικού → Λεπτομέρειες → «Αποτύπωμα». Πρέπει να είναι ίδιο με το παραπάνω. Αν τα Windows γράφουν «η ψηφιακή υπογραφή δεν είναι έγκυρη», το αρχείο έχει αλλάξει: **μην το ανοίξεις**.

Οι ενημερώσεις μέσα από το πρόγραμμα εγκαθίστανται **μόνο** αν έχουν αυτή την υπογραφή.

## Παρατηρήσεις, προβλήματα, ιδέες

Μέσα από το πρόγραμμα: **«✉ Παρατηρήσεις»**, ή απευθείας στα **[Issues](https://github.com/pfournar/my-miner/issues)**. Οι αναφορές είναι δημόσιες: **μη γράψεις wallets, κωδικούς ή προσωπικά στοιχεία**.

## Σημειώσεις

- Το My Miner **δεν περιέχει miners**. Κατεβαίνουν, μόνο όταν το ζητήσεις, από το επίσημο GitHub των δημιουργών τους, με δικές τους άδειες και fees. Το Windows Defender τους θεωρεί «πιθανώς ανεπιθύμητο λογισμικό». Η Βοήθεια (F1) εξηγεί τι να κάνεις.
- Τα κέρδη είναι **εκτιμήσεις** με τα στοιχεία της στιγμής και **δεν** είναι οικονομική συμβουλή. Το mining ζεσταίνει την κάρτα και καταναλώνει ρεύμα.
